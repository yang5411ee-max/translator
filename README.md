# 雙向即時翻譯

面對面的雙向翻譯網頁。手機放在兩人中間：下半部是你，上半部倒轉朝向對方。說完停一下就會翻譯、念出來，接著換聽對方說。

- 網址：https://yang5411ee-max.github.io/translator/ （第一次要用帶金鑰的完整連結開，之後記在瀏覽器裡）
- 收音：瀏覽器內建語音辨識（Android 用 Chrome、iPhone 用 Safari）
- 翻譯：呼叫作者自己的 Google Apps Script（LanguageApp），要有金鑰才能用；金鑰不在這個倉庫裡
- 朗讀：手機內建語音
- 對話不會儲存，關掉頁面就清空

`apps-script/程式碼.gs` 是翻譯服務的程式（金鑰已拿掉）。
