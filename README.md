# 雙向即時翻譯

面對面的雙向翻譯網頁。手機放在兩人中間：下半部是你，上半部倒轉朝向對方。

- 網址：https://yang5411ee-max.github.io/translator/ （第一次要用帶金鑰的完整連結開，之後記在瀏覽器裡）
- 收音方式（「⋯」裡切換）
  - 自動偵測（AI，預設）：按一次麥克風後一直收音。手機切出每一句話，送給 Google Gemini 判斷是誰、說哪種語言，同時轉寫和翻譯。同一個人連說好幾句也不會亂。
  - 手機辨識（輪流）：瀏覽器內建語音辨識，說完停一下換聽對方。
- 打字翻譯：呼叫作者自己的 Google Apps Script（LanguageApp）
- 朗讀：手機內建語音；念的時候不收音，避免把自己的聲音再翻一次
- 金鑰：Apps Script 金鑰（#k=）和 Gemini 金鑰（#g=）只放在連結裡，開過一次就存在瀏覽器；都不在這個倉庫裡
- Gemini 免費版的內容可能被 Google 用來改進產品，請勿說個案敏感資料
- 對話不會儲存，關掉頁面就清空

`apps-script/程式碼.gs` 是打字翻譯服務的程式（金鑰已拿掉）。
